# 🌤️ Temply

> Controle de clima minimalista e moderno, desenvolvido com foco em performance e acessibilidade.

O **Temply** é um dashboard de clima no estilo SaaS para consulta de previsão do tempo em tempo real, utilizando a API pública e gratuita da [Open-Meteo](https://open-meteo.com/).

---

## 🚀 Funcionalidades

- 🌡️ **Temperatura Atual:** Exibição imediata da temperatura e condição climática.
- 💨 **Métricas Detalhadas:** Vento, umidade e sensação térmica.
- 📅 **Previsão Semanal:** Visualização dos próximos dias.
- 🔍 **Busca por Cidade:** Consulta dinâmica de qualquer localidade.
- ♿ **Acessibilidade:** Estrutura HTML semântica com suporte completo a leitores de tela (`aria-label`, `aria-hidden` e rotulagem correta).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Semântico e acessível)
- **CSS3** (Estilo SaaS moderno com variáveis CSS e Dark Mode)
- **JavaScript (ES6+)** (Consumo da API via `fetch` assíncrono)
- **Open-Meteo API** (Dados meteorológicos em tempo real)

---

## 💻 Como Rodar o Projeto

Como o projeto é construído apenas com tecnologias nativas (Vanilla JS), não é necessário instalar dependências com Node/NPM.

1. **Clone este repositório:**
   ```bash
   git clone [https://github.com/seu-usuario/temply.git](https://github.com/seu-usuario/temply.git)
   ```

Navegue até a pasta do projeto:

    ```bash
    cd temply
    ```

Abra o arquivo index.html:

- Basta dar dois cliques no arquivo index.html, ou

- Utilizar a extensão Live Server no VS Code para rodar um servidor local.
